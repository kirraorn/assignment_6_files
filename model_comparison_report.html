Key findings

  • Metric choice. 3 different model(s) come out on top depending on the metric; across 20 metrics, Logistic regression wins 3, Decision tree wins 4, Random forest wins 13.
  • Accuracy. Always predicting 'no injury' scores 83.4% accuracy. At the default 0.5 threshold the models score Logistic regression 86.5%, Decision tree 86.5%, Random forest 86.6%, but their recall is 26%, 27%, 27%, so accuracy hides how many injury crashes are missed.
  • Predictive performance. By PR-AUC, Random forest is best (0.5429). The paired bootstrap shows it is clearly ahead of every other model. By log loss, Random forest is best (0.3456). The paired bootstrap shows it is clearly ahead of every other model. By ROC-AUC, Random forest is best (0.8083). The paired bootstrap shows it is clearly ahead of every other model.
  • Class-specific performance. To catch 90% of injury crashes, the precision (share of alerts that are real injuries) is Logistic regression 24.8%, Decision tree 24.9%, Random forest 25.3%; Random forest is best here.
  • Generalization. Train-to-test PR-AUC gap: Logistic regression -0.0015, Decision tree +0.0087, Random forest +0.0315. Logistic regression generalizes most tightly.
  • Calibration. Raw ECE: Logistic regression 0.0049, Decision tree 0.0042, Random forest 0.0043; Decision tree is best calibrated out of the box. Recalibration lowered ECE for: isotonic for Logistic regression, Platt for Decision tree, isotonic for Decision tree, Platt for Random forest, isotonic for Random forest.
  • Robustness to missing data. With 30% of values missing, the share of clean PR-AUC retained is Logistic regression 82%, Decision tree 83%, Random forest 85%; Random forest degrades least.
  • Dependence on crash type. Removing crash type changes PR-AUC by Logistic regression -0.230, Decision tree -0.221, Random forest -0.227 while removing weather, lighting or time changes it far less, so the models lean heavily on one feature.
  • Distribution shift. Under the seasonal shift (train on warm months, test on winter) ROC-AUC changes by Logistic regression -0.0152, Decision tree -0.0121, Random forest -0.0151; Decision tree holds up best. For police beats unseen in training, ROC-AUC changes by Logistic regression -0.0083, Decision tree -0.0079, Random forest -0.0065.
  • Uncertainty. Entropy gap between wrong and correct predictions: Logistic regression 0.269 bits, Decision tree 0.292 bits, Random forest 0.294 bits. Bootstrap PR-AUC interval widths: Logistic regression 0.017, Decision tree 0.016, Random forest 0.016.
  • Subset performance. Weakest well-sampled group by ROC-AUC: Logistic regression on 'SPEED_BIN: >35' (0.668); Decision tree on 'SPEED_BIN: >35' (0.672); Random forest on 'SPEED_BIN: >35' (0.697). Spread between best and worst group: Logistic regression 0.211, Decision tree 0.227, Random forest 0.195.
  • Computational cost. Training time: Logistic regression 3.2s, Decision tree 4.5s, Random forest 395.7s; model size: Logistic regression 7 KB, Decision tree 52 KB, Random forest 96,041 KB.
  • Interpretability. Most important feature by permutation importance: Logistic regression FIRST_CRASH_TYPE (0.316), Decision tree FIRST_CRASH_TYPE (0.313), Random forest FIRST_CRASH_TYPE (0.323). Rank correlation of feature importance between models ranges from 0.63 to 0.83.
  • Scenario: Emergency dispatch. Random forest scores highest (88/100).
  • Scenario: Limited follow-up capacity. Random forest scores highest (100/100).
  • Scenario: Calibrated risk estimates for planning and budgeting. Random forest scores highest (81/100).
  • Scenario: Messy or changing data. Random forest scores highest (100/100).
  • Scenario: Cheap and explainable. Logistic regression scores highest (69/100).
  • Scenario: Balanced. Random forest scores highest (65/100).
